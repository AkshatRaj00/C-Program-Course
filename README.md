The repository AkshatRaj00/C-Program-Course contains self‑contained C source files and compiled executables that illustrate fundamental concepts such as pointers, recursion, control structures, and function calling conventions for an introductory programming course. The `docs/ARCHITECTURE.md` file (and a simple Mermaid flowchart) outlines how each example demonstrates a specific language feature, with inputs being source code files and outputs the corresponding compiled binaries.
